# 川越1日プランナー

朝9時から翌朝までの時間割に、見どころ・食事・体験・泊まりのカードを置いて、川越の1日旅を組むゲームです。日本語・English・中文・한국어で遊べます。

- 遊ぶ: <https://satou-aaaaa.github.io/kawagoe-1day/>
- カード：蔵の町並み・菓子屋横丁・時の鐘のあたり・喜多院・仙波河岸史跡公園・河越館跡史跡公園・18時の鐘の夕暮れ蔵さんぽ・お昼・夕ごはん・泊まり・朝さんぽ など16枚
- 結果：「町にいた時間」「使ったお金の目安」「混雑（住む人の困りごと）」の3つの点と、ひとことの講評。中心の通りは昼ほど混みます。夜と朝・中心の外・泊まりを入れると点が上がります。
- 星：その手札でいちばん高い点に近いほど増えます。
